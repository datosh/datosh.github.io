If you spend any time in this space, it doesn't take long for you to hear about VEX documents and statements. VEX stands for Vulnerability Exploitability eXchange: a machine-readable security advisory that tells you whether a specific software product is actually exposed to a known vulnerability.

SBOM-Based Scanning#

A common approach to scan a program for vulnerabilities is to:

  1. Generate a Software Bill of Materials (SBOM)
  2. Scan the components noted in the SBOM for known vulnerabilities

Using v0.38.0 of the golang.org/x/text library, every team using this approach sees the same two findings.
